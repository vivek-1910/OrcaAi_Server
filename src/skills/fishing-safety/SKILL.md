# Fishing safety assessment

Use the `assess_fishing_conditions` tool before giving any go/no-go fishing answer.
The tool returns the authoritative decision state for this request. Explain its
decision; never replace it with model intuition. Structured Open-Meteo forecast
data can support an operational result when government feeds are temporarily
unavailable, but the result must stay conservative and tell the fisher to
verify local notices. Use restricted Scoutify search for secondary current
weather/marine context only when useful; web snippets can never override the
assessment or create a numeric safety verdict.
